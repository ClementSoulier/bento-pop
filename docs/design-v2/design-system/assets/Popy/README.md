# Popy

Les humeurs de Popy, la mascotte de Bento Pop, en PNG 1000 × 1000 sur fond transparent. Les composants `Popy`, `Avatar`, `AskSheet`, `Dialog` et `EmptyState` les embarquent déjà : ces fichiers servent à l'app native et aux visuels faits hors de l'app.

| Fichier | Humeur (`mood`) | Quand |
| --- | --- | --- |
| popy-content.png | `content` | Accueil, succès, demande bienveillante |
| popy-fille.png | `bisou` | Célébration, attachement |
| popy-intello.png | `intello` | Explication, compte, sérieux |
| popy-gene.png | `gene` | Moment délicat, perte possible |
| popy-nani.png | `surpris` | Surprise, rien trouvé, nouveauté |
| popy-enerve.png | `enerve` | Blocage, refus |
| popy-intello-enerve.png | `intello-enerve` | Pas encore utilisée dans les écrans |
| popy-malade.png | `malade` | Panne, maintenance |
| popy-diable.webp | `diable` | Avatar uniquement |

- Une Popy par écran au plus. Tailles et règles : section « Popy et le design émotionnel » du guide.
- Popy ne se recolore pas, ne se déforme pas et ne se redessine pas ; elle se pose telle quelle sur tous les fonds du système, clairs ou sombres.
- `popy-diable.webp` est provisoire : une découpe de 320 px faite dans une capture de la 2.0, faute de fichier d'origine. À remplacer par le PNG source dès qu'il est retrouvé.
