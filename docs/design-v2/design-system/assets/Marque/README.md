# Marque

Le logo Bento Pop et les icônes de l'application.

| Fichier | Usage |
| --- | --- |
| bento-pop-logo.png | Le logotype BENTO POP (lettres crème, contour encre, Popy en guise de O), 3303 × 761 sur fond transparent. En tête de La table, sur l'accueil et sur l'image partagée uniquement (composant `Logo`). |
| app-icon-1024.png | L'icône de l'app, 1024 × 1024 : Popy content sur `yolk-500` semé de pois `yolk-300` (composant `AppIcon`). Le fichier reste carré : iOS et Android arrondissent les coins eux-mêmes. |
| notification-icon-96.png | La petite icône Android de la barre d'état, 96 × 96 : la silhouette de Popy en blanc sur fond transparent, seule forme qu'Android garde. Sur une tuile claire elle paraît vide : c'est normal. |

- Le logo ne se recolore pas, ne se déforme pas et ne se redessine pas.
- Dans les écrans, l'icône d'app n'apparaît que dans `InAppNotice` et dans les maquettes de notifications du système.
