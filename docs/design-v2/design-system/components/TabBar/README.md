# TabBar

Les cinq onglets de l'app, Compose au centre dans sa pastille jaune.

**Le consommateur fournit** : `active` (`table`, `trouver`, `compose`, `notifs`, `profil`), `notifs` (nombre de nouveautés), `mood` et `color` de l'avatar de la personne pour l'onglet Profil.

- Toujours les cinq onglets, dans cet ordre, libellés visibles.
- L'onglet courant passe en icône pleine et en libellé gras ; l'onglet Profil montre l'avatar cerclé.
- Visible sur les racines et les écrans poussés ; masquée sous une feuille, une boîte de dialogue ou un parcours de compte.
