# Sheet

La feuille qui monte du bas : chercher une case, commentaires, pourquoi, signaler.

**Le consommateur fournit** : `title`, `eyebrow` (et `eyebrowCategory` pour sa puce), `subtitle`, `height` (`full`, `large`, `auto`), `close` (`icon`, `text`, `none`), `action` (lien texte à droite, ex. « Vider »), et le contenu en enfants ; une action collée en bas va dans `SheetFooter`.

- Fermeture en haut à droite ; la poignée permet de glisser pour fermer.
- La barre d'onglets disparaît sous le voile.
