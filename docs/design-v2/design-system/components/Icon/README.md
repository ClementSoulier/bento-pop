# Icon

Les pictogrammes Phosphor Icons, en graisse `bold` par défaut et `fill` pour l'état actif.

**Le consommateur fournit** : `name` (nom Phosphor), `size` (24, 20 en ligne dense, 26 dans la barre d'onglets), `weight` (`bold`, `fill`, `regular`), `label` quand l'icône est seule à porter un sens.

- Les icônes prennent la couleur du texte (`currentColor`).
- Jamais d'émoji à la place d'une icône.
