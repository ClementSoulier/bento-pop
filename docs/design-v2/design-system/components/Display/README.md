# Display

Le titre d'affiche en Extenda 100 Yotta, réservé aux moments de marque.

**Le consommateur fournit** : le texte, `size` (`xl` 44, `l` 32, `m` 24), `outline` pour une fin en lettrage autocollant (crème cerclée d'encre), `align`.

- Une fois par écran, quatre mots au plus, sur `bg-brand` de préférence.
- Jamais pour un titre d'écran courant : c'est le rôle de `title-1`.
