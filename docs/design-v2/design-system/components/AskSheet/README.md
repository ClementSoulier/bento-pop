# AskSheet

La demande bienveillante avec Popy, avant une autorisation du système ou un engagement.

**Le consommateur fournit** : `mood`, `title` (la question), `message` (une phrase), `primary`, `secondary`, `secondaryVariant`, `confetti` pour une célébration.

- Avant la boîte du système (notifications), après la publication (« Garde ton bento »), pour les éditions.
- « Plus tard » ou « Non merci » se contente de fermer la feuille, sans reproche.
