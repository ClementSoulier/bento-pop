# Sticker

Une étiquette penchée façon autocollant, pour annoncer un moment de marque.

**Le consommateur fournit** : le texte (enfant ou `label`), `tone` (`ink` par défaut, `yolk`, `rice`), `tilt` (−6 à 6 degrés).

- Uniquement sur les moments de marque (accueil, image partagée) : « L'app companion », « 6 cases · 6 choix ».
- Trois mots au plus, en capitales automatiques.
