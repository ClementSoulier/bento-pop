# AppIcon

L'icône de l'app : Popy content sur `yolk-500`, coins arrondis par le système.

**Le consommateur fournit** : `size` en pt.

- Sert dans `InAppNotice` et dans les maquettes de notifications. Le fichier 1024 × 1024 et la petite icône Android (silhouette blanche) sont dans le groupe d'éléments « Marque ».
