# ItemCard

Un item du catalogue en résultat de recherche : affiche 2:3, titre, sous-titre.

**Le consommateur fournit** : `item` (`title`, `subtitle`, `image`), `category`.

- Toujours en grille de trois (`ItemGrid`) dans la feuille de recherche d'une case.
- Titre sur deux lignes au plus ; l'année ou le métier en sous-titre.
