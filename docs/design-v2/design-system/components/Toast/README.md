# Toast

Le message bref qui confirme une action, en bas de l'écran.

**Le consommateur fournit** : `message`, `icon`, `action` (« Annuler »), `offset` (98 au-dessus de la barre d'onglets par défaut, 46 sans barre).

- Jamais en haut de l'écran : il ne couvre ni le titre ni le bouton retour.
- 4 s, 6 s avec une action ; il s'efface quand on le touche.
