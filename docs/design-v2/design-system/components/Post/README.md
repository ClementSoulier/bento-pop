# Post

Un bento dans La table : l'auteur, le plateau, les actions.

**Le consommateur fournit** : `handle`, `name`, `time`, `mood` et `color` de l'avatar, `items` (ou `slots`), `likes`, `liked`, `comments`, `commentLabel`, `showLikes`.

- Un post par hauteur d'écran environ : rien entre deux posts qu'un espace de 22 pt.
