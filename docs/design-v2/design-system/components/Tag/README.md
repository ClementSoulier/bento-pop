# Tag

La puce de catégorie : FILM, SÉRIE, ARTISTE, SON, CRÉA, LIEU.

**Le consommateur fournit** : `category`, `variant` (`media` encre sur une case, `surface` en couleur sur fond clair, `plain` en point coloré dans une liste), `label` pour remplacer le libellé court, `icon` pour ajouter l'icône de catégorie.

- La couleur ne parle jamais seule : la puce écrit toujours la catégorie.
