# IconButton

Un bouton réduit à son icône, avec une zone tactile de 44 pt.

**Le consommateur fournit** : `icon`, `label` (obligatoire, lu par les lecteurs d'écran), `variant` (`plain`, `tonal`, `outline`, `media` sur une image), `size` (`md`, `sm`), `badge` (nombre), `active` pour un bouton bascule.

- `tonal` pour fermer une feuille ; `plain` dans les barres ; `media` posé sur une image.
