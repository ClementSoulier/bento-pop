# ShareCard

L'image partagée au format story, 1080 × 1920 px.

**Le consommateur fournit** : `handle`, `items` (ou `slots`), `scale` pour l'aperçu.

- Le contenu reste dans les zones sûres des stories : 120 px en haut, 300 px en bas, où s'affichent les interfaces d'Instagram et TikTok.
- L'adresse `bento-pop.com/u/<pseudo>` et l'invitation « Compose le tien sur Mon Bento Pop » closent l'image.
