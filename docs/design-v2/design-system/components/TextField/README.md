# TextField

Le champ de saisie, avec son libellé visible au-dessus.

**Le consommateur fournit** : `label`, `placeholder`, `value`, `prefix` (« @ »), `helper` et `helperRight` (aide et compteur sous le champ), `counter` (dans le champ), `error`, `multiline`, `focused`.

- Le libellé reste toujours visible : le texte d'exemple n'en tient pas lieu.
- Actif : contour encre de 2 pt et halo `accent-soft`. Erreur : contour `text-danger`, message avec icône.
