# Popy

La mascotte de Bento Pop, dans l'humeur du moment : elle porte toutes les émotions de l'app.

**Le consommateur fournit** : `mood` (`content`, `bisou`, `intello`, `gene`, `surpris`, `enerve`, `intello-enerve`, `malade`, `diable`), `size` en pt, `tilt` en degrés (±10), `wiggle` pour le dandinement au repos, `alt` si l'image porte un sens que le texte voisin ne dit pas.

- Une Popy par écran au plus, choisie avec le tableau des humeurs du guide.
- Tailles : 52–64 (carte), 76 (dialogue), 88–120 (parcours, état vide), 150–190 (moment de marque).
- Décorative par défaut (`alt=""`) : le texte à côté dit déjà le message.
- `diable` vient d'une capture de la 2.0 en attendant le fichier d'origine.
