# ListRow

Une ligne de liste : icône, titre, description, et à droite un chevron, une flèche externe, un interrupteur ou une attente.

**Le consommateur fournit** : `icon`, `title`, `subtitle`, `note` (texte gras sous la description, pour une conséquence), `detail` (valeur à droite), `trailing` (`chevron`, `external`, `switch`, `spinner`, `none`), `checked`, `tone` (`danger`), `strong`.
