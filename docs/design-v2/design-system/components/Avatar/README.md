# Avatar

La Popy choisie par un compte, posée sur une teinte du garde-manger et cerclée d'encre.

**Le consommateur fournit** : `mood` (la Popy du compte), `color` (`yolk`, `ume`, `thon`, `sakura`, `shiso`, `ramune`, `wasabi`, `rice`), `size` (`xs` 24, `sm` 32, `md` 44, `lg` 56, `xl` 96 ou un nombre), `label` quand l'avatar est seul à désigner la personne.

- 44 dans les listes et notifications, 36 dans les commentaires, 96 en tête de profil, 26 dans la barre d'onglets.
- Toujours accompagné du pseudo à côté ; sinon, donne `label="@pseudo"`.
