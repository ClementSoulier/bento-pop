# List

Un groupe de lignes, avec un en-tête et une note de bas.

**Le consommateur fournit** : `header` (2 ou 3 mots, en sur-titre), `footer` (note en `text-secondary`), `plain` pour une liste sans carte, les `ListRow` ou `RadioRow` en enfants.

- Les réglages sont faits de groupes séparés de 24 pt ; la ligne destructive vit seule dans son groupe.
