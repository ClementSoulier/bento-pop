# BentoTile

Une case du bento, utilisable seule pour un aperçu d'item.

**Le consommateur fournit** : `item` (ou rien pour une case vide), `category`, `size` (`xl`, `l`, `s`), `mode`, `prompt`, `next`.

- Préfère `Bento` : une case isolée ne sert qu'à illustrer un item dans un message ou une aide.
