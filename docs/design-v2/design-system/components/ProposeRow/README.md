# ProposeRow

La ligne pour proposer un item absent du catalogue.

**Le consommateur fournit** : `query` (le texte cherché), `subtitle` (« Proposer au catalogue (validé par l’équipe) » par défaut).

- Toujours sous les résultats, et seule quand il n'y en a aucun (avec « Aucun résultat trouvé » et Popy surpris).
