# ActionBar

J'aime et commenter, sous un bento.

**Le consommateur fournit** : `likes`, `liked`, `comments`, `commentLabel` (« Commenter » quand il n'y a pas encore de commentaire), `showLikes={false}` quand la personne cache ses j'aime, `share`.

- Le cœur saute et vibre à l'appui ; aimé, il passe en `like` plein.
